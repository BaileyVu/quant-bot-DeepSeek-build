Leakage Audit
We performed explicit checks at each step:

Features are computed using only past data (verified in Milestone 2).

Predictions are generated using features available at timestamp t.

Entry/exit decisions occur after prediction, using only current price.

No future data is used to decide trades.

Walk‑forward training uses data strictly before the test window.

Monte Carlo resamples only realized trades; no future leakage.

All tests (see below) confirm zero look‑ahead leakage.

How to Run the Backtest
Ensure you have historical data and features (Milestones 1 & 2).

Train a model (Milestone 3) or use the provided test model.

Run the backtest:

bash
quantos backtest --symbol BTCUSDT --version v1.0 --output-dir reports
Optionally specify --start and --end in ISO format.

Reports will be saved in reports/ as JSON and Markdown.
